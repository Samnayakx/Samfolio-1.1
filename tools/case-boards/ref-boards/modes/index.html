The question

Can any fashion user get a high-quality result without writing a prompt?

Users don't know how to prompt

Blank-page prompting put the burden on the user's language skills

Too much prompting makes AI hallucinate

Especially with visuals, long prompts led to unpredictable results

Hesitated before typing

Noticed while shadowing users

Reused vague prompts

“change color”, “Make this editorial”, “Change the Model”

→

Tried first

Smarter prompt templates

Less blank page, but still language-precise. Hallucination did not drop.

Failed

Tried second

System-generated prompts

Hid complexity. Hard to predict, and users couldn't tell why results changed.

Failed
→

What that told us

Remove the need to prompt

Modes: structured entry points into AI capability

An MVP in 3 weeks, then shadowing fashion teams on it

Both fixes failed, which was the most useful result of the quarter
