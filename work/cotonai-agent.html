    Case study ( 02 ) · CotonAI

    Designing an AI agent that understands how creative teams work.

    Founding product designer at CotonAI: moving from an image generator to an agent that carries creative intent across the whole workflow.

    Role
    Founding Product Designer
    Timeline
    2025 – Present
    Scope
    Product strategy, user research, interaction design, agent UX, design systems
    Focus
    0→1 product design, human–AI interaction, creative tools

    01Overview

    From an image generator to an agent that remembers the brief.

    As founding product designer at CotonAI, I owned product strategy as well as design. The question I kept bringing back to the team wasn't “how do we generate better images?” but “why does every prompt start from zero?”

    This is how that question moved CotonAI from a visual workspace toward an agent that carries creative intent across a whole collection.

    • Problem: Every prompt started over.

      The AI forgot why a colour was rejected or which silhouette was approved.

    • Solution: The canvas is the context.

      An agent that plans, executes and returns work to the canvas, with designers approving each step.

    • Outcome: 71% first-pass

      Designs accepted without a revision in the Steele pilot.

    02Problem

    We didn't need another AI image generator.

    The real problem wasn't creating an image. It was everything that happened before and after it. A designer could generate 20 variations in minutes, but the AI wouldn't remember why a color was rejected or which silhouette was approved. Every new prompt felt like starting over.

    • No memory of decisions

      Rejected colors and approved silhouettes were lost between prompts.

    • Context scattered across tools

      References, material constraints, brand identity and feedback lived in different places.

    UsersFashion teams ran on invisible context that no prompt could carry.

    Working with fashion brands and production teams, we saw how much creative work depended on invisible context that no prompt could carry.

    03Hypothesis

    If the canvas carries the context, a prompt stops starting from zero.

    The canvas shouldn't only hold the work. It should be the context an agent understands the work through: why a color was rejected, which silhouette was approved, what the brief asked for.

    The agent plans and executes while the designer approves each step. Only the live workspace has run in a pilot; the agent itself is still a proposal.

    ConstraintsThe workspace is live, the agent is a proposal, and the designer stays in control.

    The live workspace is the foundation. Persistent creative memory, multi-step orchestration and richer agent controls are the next product direction, so this study keeps what ran in the pilot apart from what is proposed.

    04Solution

    The canvas becomes the context, and the agent works inside it.

    We started CotonAI as a collaborative visual workspace where designers could sketch, generate, edit, explore colorways and review work together on a shared canvas. The bigger opportunity emerged from those workflows: the canvas shouldn't just hold the work. It should become the context through which an agent understands the work.

    Rejected designsThree directions we didn't ship.

    Each of these was a simpler way to put AI in the workflow. Each lost the context, the continuity or the control that the shipped agent keeps.

    SolutionThree product decisions for the agent experience.

    The proposed workflow became a loop the agent runs with the designer. The design challenge was making complex execution feel understandable, without exposing unnecessary technical complexity.

    • Show the agent what you're working on

      An image, sketch, annotation or selected region communicates intent, so you don't have to describe it.

    • Execution, not just generation

      The agent plans steps, selects tools, generates alternatives and returns outputs to the canvas.

    • Humans stay creative directors

      Visible progress, contextual feedback and approval checkpoints keep creative judgment with the designer.

    Decision 1: Context before conversation

    • Before

      Designers had to explain everything through prompts.

    • Change

      An image, sketch, annotation, garment reference or selected canvas region can communicate intent.

    • Result

      From “describe exactly what you want” to “show the agent what you're working on.”

    Decision 2: Execution, not just generation

    • Before

      A creative task rarely ends with one image, but the tool did.

    • Change

      A harness for managing context, planning steps, selecting tools, generating alternatives and returning outputs to the canvas.

    • Result

      Multi-step work that stays understandable.

    Decision 3: Humans remain creative directors

    • Risk

      Autonomy is useful until an agent makes the wrong creative decision.

    • Change

      Visible progress, contextual feedback, version comparison and approval checkpoints.

    • Result

      The agent handles repetitive execution. The designer keeps creative judgment.

    05Learning

    Early pilot outcomes validated the collaborative workflow.

    These are early workspace and pilot outcomes, not evidence that the proposed autonomous agent architecture has already achieved the same results.

    • Review comments: 188

      Designs accepted without a revision, Steele pilot

    • Revisions per design: 3–5 → 1–2 (Typical)

      Before 3–5 vs With CotonAI 1–2. Typical revisions in the Steele pilot. Bars sit at the midpoint of each range.

    • Visual assets per month: ~5,000

      Workflows supported through CreateNet

    LearningMake intelligence understandable, controllable and useful inside real work.

    The hardest part of designing AI products isn't making intelligence more powerful. It's making it understandable, controllable and useful inside real work.

    The live workspace established the foundation. Persistent creative memory, multi-step orchestration and richer agent controls are the next product direction: moving from AI that generates creative outputs toward AI that helps teams carry creative intent across an entire workflow.
