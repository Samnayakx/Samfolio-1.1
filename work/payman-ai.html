    Case study ( 07 ) · Payman

    Payman AI: rebranding an agentic banking site for institutional trust.

    Agents that move real money, behind a first screen that read like a friendly startup. I rebuilt the brand around control.

    Role
    Brand and Web Designer, end to end
    Timeline
    2026
    Format
    Portfolio redesign of paymanai.com, solo
    Skills
    Brand audit, positioning, visual identity, web design, front-end build

    The Setup

    Real money, and a buyer who trusts nothing yet.

    Payman deploys agents that move real money inside a bank's own systems. This is my redesign of paymanai.com, as it stood.

    The Tension

    The page sold warmth to a buyer who needs proof.

    55%of U.S. consumers already ask AI about money. TD Bank, 2026
    200M+people ask ChatGPT about money every month. OpenAI, 2026

    The Decision

    Sell the control, not the magic.

    The System

    An identity derived from the position, not from taste.

    The Page

    One question per section, in the order a buyer worries.

    The Impact

    The surfaces now match the claim.

    Same facts, same viewport. This is a portfolio redesign: no production metrics, and the chat and approval code are illustrative.

    View the prototype

    The Takeaway

    In regulated software, show the control before the capability.

    The page works because it drops the category's vocabulary of magic and warmth. Limits: a free stand-in serif, and no testing with real bank buyers. Next, I'd see whether compliance leads find the kill switch unprompted.
