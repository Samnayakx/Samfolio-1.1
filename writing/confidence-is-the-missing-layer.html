    Confidence Is the Missing Layer in AI Interfaces

    When Should AI Ask and When Should It Act?

    All writing Substack

    Confidence Is the Interface

    Most AI tools today follow the same pattern.

    The system performs an action and then asks what to do next.

    You see this in tools like Claude and Cursor. After editing code, the system pauses and asks:

    • Run migrations
    • Update API layer
    • Generate tests
    • Something else

    At first this feels helpful. The AI is guiding the workflow.

    But over time something becomes clear.

    The AI isn’t actually deciding anything.
    It’s just asking questions.

    Why This Pattern Exists

    The option-based model exists mainly for safety.

    AI systems are still unreliable, so confirmations help prevent costly mistakes when modifying code, deleting files, or changing databases.

    It has benefits:

    • Faster than writing prompts
    • Shows the system’s suggested next step
    • Keeps users in control of risky actions

    But when this becomes the default interaction model, the experience starts to break.

    The Real Issue

    Most AI interfaces treat every decision as equally uncertain.

    That’s the mistake.

    Agents should behave differently depending on confidence.

    When confidence is high, the system should act automatically.

    When confidence is moderate, it should offer options.

    When confidence is low, it should ask a clarifying question.

    High confidence → act
Medium confidence → suggest
Low confidence → ask

    Right now many systems operate entirely in the middle state.

    They ask constantly.

    The Solution : The Confidence UX Layer

    Imagine the system evaluating every decision through three states.

    High confidence

    The system executes silently.

    Example:
    A code schema changed, so the system regenerates types automatically.

    Medium confidence

    The system proposes options.

    Example:
    Looks like you want a Dark mode UI. Which design system should I use?

    • Shadcn
    • Radix
    • Type here

    Low confidence

    The system asks for clarification.

    Example:
    What are you trying to generate here?

    The key idea is simple.

    Most actions should fall into the first category.

    Good agents act more than they ask.

    The Future Interaction Pattern

    Option-driven interfaces are a transitional design.

    They exist because models are still unreliable and safety matters.

    But the long-term direction is different.

    Agents will move toward:

    Autonomous execution
+ rare high-quality interventions

    The system will act continuously in the background, surfacing decisions only when human judgment is truly required.

    When that happens, the interface will change.

    The AI will stop asking what to do.

    And start behaving like someone who already knows.
